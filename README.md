# Tetris

轻量、极简、像素风的离线俄罗斯方块。棋盘在桌面窗口中从顶部铺到底部，模式和工具位于两侧；中英文点阵字体、低分辨率画布和硬边方块构成统一的街机像素画面。打开就能玩，关闭会保存当前进度，下次继续。

## 快速开始

- **在线游玩：**[打开 Tetris](https://chenyb2006.github.io/tetris/)，可直接分享链接，无需安装。电脑推荐键盘，触屏设备可使用屏幕按钮。每个人的进度保存在各自浏览器里，不提供账号同步或在线排行榜。

- **这台 Mac：**双击 `Tetris.app`，关闭窗口或按 `⌘Q` 即可保存并退出。可以把它拖到 Dock，之后一键打开。
- **通用网页版：**用现代浏览器打开 `index.html`。无需联网、注册或安装依赖。
- **重新构建 Mac 应用：**运行 `build-desktop.sh`，或在应用尚不存在时双击 `Launch.command`。构建使用系统 Swift 与 WebKit，需要已安装 macOS Command Line Tools 与 Node.js；运行游戏本身无需这些开发工具。只改网页时，可运行 `node build-coach-worker.js` 同步离线教练包。

原生应用使用 macOS 自带的 WebKit，无需打包一个浏览器。应用菜单支持 `⌘W` 保存并关闭、`⌘R` 保存并刷新、`⌘,` 打开设置和 `⌘Z` 撤销落子；切换到其他窗口时会暂停。

棋盘、暂存和预览只在内容变化或播放特效时重绘，计时显示独立更新；暂停、待开始和静止的结束界面会停止动画回调。运行时保留完整的重力、锁定与按键计时，不降低操作或特效的刷新速度。

## 玩法与设置

| 模式 | 玩法 |
| --- | --- |
| 马拉松 | 无限挑战，每消除 10 行升一级。 |
| 40 行竞速 | 以最快速度消除 40 行。 |
| 两分钟 | 在 120 秒内争取最高分。 |
| 禅模式 | 无自动重力，自行软降或硬降，慢慢思考。 |
| 复古模式 | 独立随机、无暂存、无落点影子、单块预览、无踢墙。经典启发规则，非 NES 精确模拟。 |

现代模式包含七种方块、七袋随机、SRS 旋转与踢墙、暂存、五块预览、落点影子、软降、硬降、T-Spin / Mini、连击、背靠背和全消计分。每块触地后的锁定延迟最多可重置 15 次。右侧「接下来」使用更大的方块与更宽的纵向间隔，便于扫视后续形状。

硬降带短促像素拖尾、落地冲击和方形火花；消行有对应行的扫光与碎屑，四消、Spin 消行和全消反馈更强。特效不等待播放完成，方块落定、消行和下一块照常响应；暂停、撤销或切换模式会清除残留。启用系统「减少动态效果」时会改为短暂轻高亮。

设置可以调整这些参数：

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| 起始等级 | 1–20 | 决定新一局的起始难度与自动下落速度。 |
| 横移启动延迟（DAS） | 50–500 ms | 按住左右键后，开始连续横移前的等待时间。 |
| 横移间隔（ARR） | 0–150 ms | 连续横移的间隔；0 表示移到边缘。 |
| 软降间隔 | 10–150 ms | 按住软降键时每下落一格的间隔。 |
| 锁定延迟 | 100–1000 ms | 方块触地后仍可调整位置的时间。 |

起始等级和锁定延迟从新一局生效；更改这两项会把该局成绩标记为「自定义」。还可切换落点影子、网格、8-bit 音效，以及街机 / 深夜 / 掌机配色。旧版存档、记录和设置直接兼容。

音效默认开启；按 `S` 打开设置，进入「音效」页可关闭或自由更改。默认移动、旋转和软降无声，硬降与落定使用下坠音色，其余事件沿用街机音色配置。内置原创离线音效库提供 **22 种选择（含无声）**，移动、旋转、软降、硬降、暂存、落定、各类消行、连击、升级、暂停、继续、开始、撤销和结束等 **18 类事件** 都有独立下拉菜单与试听按钮，也可一键恢复默认。总音量为 0–100%，默认 100%。网页版需首次点击或按键后才能播放声音。Mac 版启动时预加载全部 PCM 音色，开启音效或回到前台时提前预热原生 AVAudioEngine；操作直接触发空闲声部，不等待网页音频通道启动，也不会排在上一段音色后播放。关闭音效、音量为零或切到后台时会停止音频设备并保留缓存。前台开启音效时，普通暂停仍保持音频热机，便于即时继续。网页版使用同样的缓存和前后台控制；原生通道不可用时会自动回退。实际听感仍受输出设备和系统音频延迟影响。

各模式独立保存一份进行中进度；历史保留最近 200 局。最高分及竞速最佳时间仅统计正常完成的标准参数成绩，重新开始的对局仍保留在历史里。使用撤销、显示过 AI 教练建议或进行过 AI 自动操作的对局会标记为「练习」，不计入标准最佳纪录。

## AI 教练

短按 **G** 随时开启或关闭 AI 提示，也可点击左侧教练开关，或在「设置 → 游戏」中切换。快捷键可在「设置 → 按键」中重新绑定；已有自定义按键会保留，如 G 已被占用，请以界面显示的教练快捷键为准。开关状态随设置保存。

开启后，棋盘中的**白色虚线推荐框与 AI 标签**显示建议摆放位置，与彩色方块及普通落点影子分开。左侧直接给出剩余操作，不显示推荐理由与搜索深度；操作会随当前方块位置更新，目标位置保持固定。若建议先使用暂存，会明确提示先换块；按建议交换后沿用同一个目标。提示模式由你操作方块。

按住 **G 约 0.7 秒**开启 AI 自动，再次长按关闭；重绑教练键后，长按同一个键切换自动。开启时会开始或继续当前一局，按建议逐步移动、旋转、暂存和落块，一局结束后稍停并自动再开。暂停、切窗、打开菜单、更换模式、撤销、重开或手动操作会停止自动；关闭后未执行的动作会立即取消。自动状态不随存档恢复，再次打开游戏由你操作。左侧显示 `AUTO` 时代表自动正在运行。自动对局永久保留「AI 自动 / 练习」标记，即使中途改手动、撤销、导出或恢复，也不计入手动最佳成绩。

教练完全离线，使用后台 Web Worker 搜索当前地形、可用暂存与可见的后续方块：现代模式最多参考接下来的五块，复古模式只参考一块且不使用暂存。搜索会在计算预算内尽量向后看，最多推演当前块加后五块；不会读取隐藏队列、随机种子或未来的未知方块。

推荐采用引擎的实际消除得分，考虑多消、T-Spin / Mini、B2B、Combo 与全清，同时权衡空洞、堆叠高度和平整度。马拉松、两分钟与禅模式在低堆安全时，会主动选择一侧井、逐步堆齐其余九列，必要时把 I 块留在暂存，攒够四行再兑现；未成形的井也会按建设进度计值。已有成熟中井可继续使用，搜索会保留不同首步的路线，避免小消方案过早挤掉建井方案。高堆、空洞与修洞需求会减弱蓄井倾向，T-Spin、全消和清行减压仍可优先；竞速模式较重视尽快完成行数。有限搜索仍不保证全局最优或最高得分。

教练也会计算操作耗时：同一落点能先旋转再直接落下时，优先走直落路线，包括边缘坑消行的情况，不会为额外 Spin 分刻意逐格软降。需要软降后旋转才能进入的卡槽和钻洞仍可推荐；搜索会按实际执行路线计算得分及后续 B2B 状态。游戏本身的 Spin 判定与计分保持一致。

每个方块只计算一次推荐，左右移动、旋转与下落时保留原来的目标；执行建议的暂存也保持前后一致。手动换成其他方块、落子生成新块或撤销后才重新计算。高速下请及时操作，后台搜索不会暂停重力或锁定计时。

一局中只要实际显示过建议，就会保留「AI 教练 / 练习」标记；之后关闭教练、撤销或重新打开应用也不会清除。该局进度和成绩照常保存，但不计入标准最佳纪录。仅打开开关、尚未显示建议的对局不会因此标记。

## 默认操作

| 按键 | 操作 |
| --- | --- |
| ← / → | 左右移动，按住可连续移动。 |
| ↑ | 顺时针旋转。 |
| Z | 逆时针旋转。 |
| A | 旋转 180°。 |
| ↓ | 软降。 |
| 空格 | 硬降，直接落下。 |
| C | 暂存 / 交换方块。 |
| U / ⌘Z（Windows / Linux：Ctrl+Z） | 撤销上一次落子。 |
| 短按 G | 开启 / 关闭 AI 提示。 |
| 长按 G（约 0.7 秒） | 开启 / 关闭 AI 自动连续游玩。 |
| Enter | 开始 / 继续。 |
| Esc / P | 暂停 / 继续。 |
| R，随后 Enter 或 R | 确认重新开始，当前对局计入历史；Esc 取消。 |
| S / ⌘,（Windows / Linux：Ctrl+,） | 打开设置。 |
| L / H | 打开历史记录 / 操作指南。 |
| 1–5 | 依次切换马拉松、40 行竞速、两分钟、禅模式、复古模式。 |
| Tab / Shift+Tab | 向前 / 向后选择界面控件；游戏中使用时会先暂停。 |
| Enter / 空格 | 激活当前选中的按钮。 |
| ← / → | 选中设置页签时切换页签；选中模式按钮时切换模式。 |
| ⌘Enter / Ctrl+Enter | 保存设置。 |
| F | 网页全屏；原生应用也可使用窗口左上角的绿色按钮。 |

移动、旋转、下落、暂存、撤销和教练开关按键都可在设置里重新绑定。常用操作、确认弹窗、设置页签、下拉菜单、试听与备份按钮均可通过键盘完成；Esc 可关闭弹窗。打开设置、记录或指南时会暂停；切回游戏后手动继续，避免自动开局。

撤销最多保留最近 **30 次落子**，会恢复方块、地形、暂存与队列，已消耗的游戏时间不会倒退。撤销历史随进度保存，关闭后重开仍可使用；旧版存档从升级后新落下的方块开始积累撤销历史。两分钟模式计时结束后无法撤销。

## 存档与备份

进度、设置与历史成绩保存在本机。关闭后重新打开，可继续未完成的一局。

运行中的连续操作合并为约每秒一次存档；暂停、切换模式、撤销、导出和关闭游戏时立即保存最新进度。重复的数据不再重复写入，原有存档格式保持兼容。

- 原生应用与各浏览器各自保存数据，彼此独立。
- 使用游戏中的导出/导入功能，可备份、恢复或迁移记录。建议定期导出备份。
- 清除浏览器网站数据会同时清除该浏览器里的游戏数据。
- 重新构建应用会保留原生应用的数据；删除系统中的应用数据或改变应用标识可能导致数据丢失。

## 文件

### GitHub Pages

`main` 分支推送后自动运行回归检查，再通过 `build-web.js` 打包并发布。发布目录采用明确的文件清单，仅包含游戏运行文件、字体及其许可，不包含个人存档、桌面应用、测试数据或截图。

本地运行 `node build-web.js`，即可在 `dist/` 获得同样的网页发布包。GitHub 仓库的 Settings → Pages 使用 GitHub Actions 作为发布来源。

- `index.html`、`styles.css`、`app.js`：游戏界面与本机数据管理。
- `engine.js`：独立游戏规则。
- `audio.js`：原创离线音效库、音色配置与缓存播放。
- `effects.js`：受控的像素硬降、落地与消行特效。
- `build-sounds.js`、`desktop/PixelAudio.swift`：构建相同音色的原生 PCM 缓存与 Mac 低延迟播放。
- `coach.js`、`coach-client.js`、`coach-worker.js`：离线教练搜索、操作路径与后台计算；`build-coach-worker.js` 生成可直接离线使用的 `coach-worker-source.js`。
- `desktop/`：轻量 Mac 窗口与应用图标源码。
- `build-desktop.sh`：构建 `Tetris.app`。
